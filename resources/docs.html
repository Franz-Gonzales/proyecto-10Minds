Enumeraciones (ENUMs)
LoanStatus
RESERVADO ENTREGADO RETRASADO
Estado inicial siempre = RESERVADO. Auto-cambia a RETRASADO si endDate < hoy y no fue entregado.
GameCategory (sugerido como tabla o enum)
Familiar Estrategia Cooperativo Party Abstracto RPG
Se puede guardar como VARCHAR flexible. Los filtros del UI muestran: Todos / Estrategia / Familiar / Cooperativo.
Relaciones entre Entidades
games ────── 1 : N ────── loans Un juego puede tener muchos préstamos
clients ────── 1 : N ────── loans Un cliente puede tener muchos préstamos
Campos Calculados / Derivados (no en BD, en resolver/servicio)
💰 totalPrice (loans)
Se calcula al crear el préstamo:
días = endDate - startDate
total = días × quantity × pricePerDay
Se persiste como snapshot para histórico.
📊 activeLoans (clients)
Campo virtual devuelto por el resolver:
COUNT(loans) WHERE status = 'RESERVADO' AND clientId = id
Visible en la tabla de clientes como "X Activos".
📈 totalHistoric (clients)
Campo virtual del resolver:
COUNT(loans) WHERE clientId = id AND isDeleted = false
"Total Histórico" visible en lista de clientes.
🟢 stockBadge (games)
No se persiste. En frontend:
stockAvailable > 0 → "X disponibles" (verde)
stockAvailable = 0 → "Agotado" (rojo)
🎯 initials (clients)
Avatar de texto si no hay foto:
fullName.split(' ').map(n => n[0]).join('').slice(0,2)
Ejemplo: "Pablo Perez" → "PP"
⏰ Auto RETRASADO
Al consultar loans, el resolver verifica:
IF endDate < TODAY AND status = 'RESERVADO'
→ UPDATE status = 'RETRASADO'
Reglas de Negocio Implementadas en Backend
🚫 Validación de Stock al Crear Préstamo
Antes de crear el préstamo:
IF quantity > game.stockAvailable → throw Error
Si pasa: game.stockAvailable -= quantity
Todo en una sola transacción TypeORM.
✅ Al Marcar como ENTREGADO
loan.status = 'ENTREGADO'
loan.deliveryDate = TODAY
game.stockAvailable += loan.quantity
En transacción atómica.
📅 Validación de Fechas
IF endDate <= startDate → throw Error
IF startDate < TODAY → throw Error
Validado en resolver antes de persistir.
📞 Unicidad en Cliente
Campos con constraint UNIQUE:
phone — no duplicar celular
dni — no duplicar cédula
email — no duplicar correo
